# Mi primer Markdown

## ¿Qué puede hacer?:

Markdown es un lenguaje de marcado ligero que se utiliza para dar  formato y estructura a documentos de texto de una manera sencilla y  legible. Puede escribir palabras en **negrita**, *en cursiva*, o código como esto: 

`document.write('Hola mundo')`



## Ejemplo de código

`<!DOCTYPE html>`

`<html>`

`<head>`

​	`<title>Hola mundo>`	

`</head>`

`<body>`

​	`<h1>Hola mundo</h1>`

`</body>`

`</html>`
